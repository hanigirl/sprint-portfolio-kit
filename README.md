# Sprint Portfolio Kit

מלווה דֵיזיין-ספרינט שהופך את **התהליך** לתיק עבודות — לא רק את העיצוב הסופי.

## התקנה (לתלמידים)

ב-Claude Code, הדביקו שתי השורות האלה:

```
/plugin marketplace add hanigirl/sprint-portfolio-kit
/plugin install sprint-portfolio@sprint-portfolio-kit
```

ואז פותחים ספרינט עם `/start-sprint ./my-project`.

---

הרעיון: תיק עבודות טוב הוא בדיוק החומר שנמחק אם לא תופסים אותו בזמן אמת — הכיוונים שנפסלו, ה"למה פסלנו", והזזת המדדים. הפלאגין תופס את זה **תוך כדי הספרינט** לתוך תיקיית הפרויקט של התלמיד, ובסוף מרכיב מהתיקייה **דף case-study מוכן-לפורטפוליו**.

הסוכן חסר-מצב: הזיכרון חי בקבצים שבתיקייה, לא בשיחה. לכן הכול נייד, ניתן לבדיקה, ושורד גם אם הסשן נשבר.

## מה יש בפנים

פלאגין אחד — **`sprint-portfolio`** — עם:

**סקילים**
- `design-journal` — תפיסה חיה. מזהה בשיחה ומציע לתעד: החלטות, מדדים שזזו, וממצאים/ציטוטים. כותב רשומות לתיקייה.
- `sprint-portfolio` — הרכבה. סורק את כל התיקייה ומרנדר `portfolio.html` (RTL, מוכן-לפורטפוליו).

**פקודות**
- `/start-sprint [נתיב]` — מקים את תיקיית הפרויקט וממלא את ה-brief.
- `/log-decision [תיאור]` — תיעוד ידני של החלטה (רשת ביטחון; הסוכן גם מזהה לבד).
- `/build-portfolio [נתיב]` — בונה את תיק העבודות בסוף.

**תבנית** — שלד תיקיית פרויקט (`brief` + `resources/ research/ decisions/ versions/ metrics/` + `journal`).

## איך עובדים

1. `/start-sprint ./my-project` — פותח את התיקייה וממלא brief.
2. עובדים מול הסוכן לאורך הספרינט. כשנופלת החלטה / זז מדד / עולה ממצא — **הסוכן מזהה ומציע לתעד** (כרטיס כן/לא). מה שנעשה מחוץ לסשן → `/log-decision`.
3. בסוף: `/build-portfolio ./my-project` → `portfolio.html`.

## מבנה תיקיית הפרויקט

```
my-project/
  brief.md        אתגר הספרינט + המדד שרוצים להזיז
  resources/      רקע: מוצר, פרסונה, מתחרים, מותג
  research/       מה למדתי: סיכומי בדיקות, ראיונות, ציטוטים
  decisions/      רשומת החלטה לכל צומת (כולל כיוונים שנפסלו ופיבוטים)
  versions/       איטרציות + הערה מה השתנה
  metrics/        before/after + מקור
  journal.md      ציר זמן (נבנה אוטומטית)
```
