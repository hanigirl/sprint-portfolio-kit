# resources/ — רקע על המוצר והשוק

כאן נכנס **כל חומר הרקע** שהסוכן צריך כדי להבין את ההקשר — מה שלא החלטת אתה, אבל חשוב לסיפור.

## מה שם פה
- **רקע על המוצר** — מה המוצר, למי, המודל העסקי, מצב קיים.
- **פרסונה** — מי המשתמש שעבורו עיצבנו (אם יש מחקר פרסונה).
- **בנצ'מרק / מתחרים** — מה ראית אצל אחרים, השראות, מה לקחת ומה פסלת.
- **מותג / הנחיות עיצוב** — צבעים, טון, מגבלות מותג.
- כל מסמך או לינק שחשוב שהסוכן ייקח בחשבון.

## איך לארגן
קובץ לכל נושא, שם ברור: `product-background.md`, `persona.md`, `competitors.md`, `brand.md`.
טקסט קצר עדיף על הדבקה ארוכה — תמצת את מה שחשוב, ושים לינק למקור אם צריך.

**למה זה חשוב:** הסוכן ימשוך מכאן את ההקשר ל-**Challenge** (מי המשתמש, למה זה חשב) ולרקע הכללי של הקייס — בלי זה הסיפור תלוש.
